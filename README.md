## 🚀 Featured Projects

### 🤖 RepoChat — RAG-Based Codebase Q&A Tool

`Personal Project · React · Vite · Express · TypeScript · Gemini API · RAG · Docker`

- Built a full-stack Retrieval-Augmented Generation (RAG) app that lets users ask natural-language questions about any public GitHub repo and get answers grounded in the actual source code, with file/line citations
- Built an ingestion pipeline that fetches a repo's files via the GitHub API, splits them into chunks, and embeds each one with Gemini for similarity search
- Integrated Gemini 2.5 Flash to generate answers strictly from retrieved code excerpts, minimizing hallucination and keeping every answer traceable
- Containerized with Docker and deployed independently as a live portfolio project

### 📍 MIITGuide — Augmented Reality Campus Navigation System

`Final Year Project · Flutter · Firebase · Unity AR`

- Developed a Flutter and Unity-based mobile application that combines augmented reality navigation with Firebase services
- Designed an offline AR indoor navigation system for a multi-story campus building
- Integrated Firebase Authentication, Firestore, Storage, and Cloud Messaging
- Built role-based features for students, guests, and administrators

### 🌐 Agent Portal System

`Internship Project · Web Development · UI Development · Testing`

- Developed and maintained an Agent Portal system for student registration and international recruitment
